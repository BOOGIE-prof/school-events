# School Events

Веб-приложение для планирования школьных мероприятий: доска идей, мероприятия с задачами
и ответственными, календарь, шаблоны, архив с файлами, уведомления о дедлайнах и рейтинг.

Бэкенд — Python (только стандартная библиотека) + SQLite. Фронтенд — React, подключается из CDN,
собирать ничего не нужно: ни Node.js, ни npm.

## Запуск локально

```bash
python3 app.py
```

Откройте http://localhost:8000. База создастся сама в `data/school.db`.

**Первый зарегистрировавшийся сотрудник получает роль «Завуч»** — зарегистрируйтесь первыми.
Все остальные регистрируются как «Учитель», повысить их может только завуч на вкладке «Пользователи».

## Роли

| Действие | Учитель | Завуч |
|---|---|---|
| Предлагать идеи, реагировать, комментировать | да | да |
| Создавать мероприятия и задачи, назначать ответственных | да | да |
| Отправлять мероприятие на рассмотрение | да | да |
| Одобрять / отклонять мероприятия | нет | да |
| Превращать идею в мероприятие | нет | да |
| Менять роли сотрудников | нет | да |
| Начислять и снимать очки вручную | нет | да |
| Менять своё имя в профиле | да | да |

## Айлық жоспар — месячный план

Вкладка «Айлық жоспар» заменяет таблицу в Excel: месяц выбирается стрелками, сверху автоматически
подставляется құндылық месяца, дальше таблица с колонками **Апта · Тақырып · Іс шаралар · Жауапты**.
Недели объединяют свои строки, как объединённые ячейки в Excel.

Заполняет и правит план завуч — прямо в ячейках, без отдельных форм. Учителя видят план только
для чтения. Ответственного можно выбрать из списка сотрудников (подсказка появляется при вводе)
или вписать любое имя текстом, если человека нет в системе.

Кнопка **CSV для Excel** выгружает план в файл, который открывается в Excel, **Печать** —
готовит таблицу к печати без интерфейса приложения.

## Очки рейтинга

| За что | Очки |
|---|---|
| Выполненная задача | +100 |
| Предложенная идея | +10 |
| Идея одобрена и стала мероприятием | +50 |
| Задача осталась невыполненной к моменту архивации мероприятия | −100 |
| Ручное начисление от завуча | любое число, со знаком |

Удаление идеи очки не отнимает: идея просто убирается с доски (в базе остаётся со статусом
`deleted`), автор сохраняет начисленные за неё очки — удаление считается нейтральным действием.

Завуч может начислить или снять любое количество очков любому участнику: в рейтинге у каждого
есть кнопка «Изменить очки» — быстрые кнопки ±50/±100, поле для своего числа и причина,
которая попадает в ленту активности. Там же история всех начислений, каждое можно отменить.

Штраф начисляется только в момент, когда мероприятие отмечают проведённым: пока оно идёт,
просроченная задача просто подсвечивается в списке и в уведомлениях. Задачи без назначенных
ответственных не штрафуют никого.

Расчёт всегда идёт от текущего состояния задач, а не от журнала событий: если задачу отметить «Готово»
уже после архивации (это можно сделать прямо в архиве), минус исчезает и превращается в +100.
Перед отправкой в архив показывается предупреждение — сколько задач останется незакрытыми
и кто из учителей сколько потеряет.

Уровень растёт каждые 500 набранных очков; отрицательный итог не опускает ниже первого уровня.

## Призовой фонд

Победитель рейтинга получает сертификат на 100 000 ₸, итоги подводятся 25 декабря, перед Новым годом.
Баннер с призом, обратным отсчётом, текущим лидером и разрывом до первого места показывается
на главной и на вкладке «Рейтинг».

Приз и дату задаёт объект `PRIZE` в начале `static/app.jsx`:

```js
const PRIZE = {
  title: "Сертификат на 100 000 ₸",
  subtitle: "победителю рейтинга учителей",
  announceDay: 25,
  announceMonth: 12,
};
```

Год подставляется сам: после 25 декабря отсчёт начинает вести к следующему году.

## Публикация в интернете

Файлы для деплоя уже готовы: `render.yaml`, `Procfile`, `Dockerfile`, `requirements.txt`.

### Render (бесплатно, рекомендуется)

1. Загрузите папку проекта в репозиторий GitHub.
2. На https://render.com → **New → Blueprint**, выберите этот репозиторий.
   Render прочитает `render.yaml` и создаст сервис с постоянным диском для базы.
3. Дождитесь деплоя и откройте выданный адрес вида `https://school-events.onrender.com`.
4. Зарегистрируйтесь первыми — получите роль завуча.

Постоянный диск обязателен: без него база SQLite стирается при каждом передеплое.
На бесплатном тарифе Render сервис засыпает после 15 минут простоя — первый запрос
после сна открывается ~30 секунд.

### Любой сервер с Docker

```bash
docker build -t school-events .
docker run -d -p 80:8000 -v school_data:/data --name school-events school-events
```

## Резервная копия базы

Вся база — один файл. Скопируйте `data/school.db` (на Render — `/var/data/school.db`).

## Структура

```
app.py              HTTP-сервер, REST API, раздача статики
db.py               схема SQLite, хеширование паролей, сессии, сборка состояния
static/index.html   страница-оболочка
static/app.jsx      весь интерфейс на React
static/styles.css   стили и дизайн-токены
```

## Безопасность

Пароли хранятся как PBKDF2-SHA256 (200 000 итераций, случайная соль). Сессии — HttpOnly-cookie
с токеном в базе. Все проверки прав выполняются на сервере: подделать роль на клиенте нельзя.
Файлы из архива отдаются только авторизованным пользователям.
